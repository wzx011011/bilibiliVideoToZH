# 大明演义 · 系列大纲（基于公开史实时间线，非小说原文提取）

**系列定位**：《大明演义》：明朝那些事风格的历史故事解说——口语化、有钩子、史实可查、表达原创。
**每集规格**：8 章原创解说词 ≈1000 字 ≈ 3 分钟；京腔侃爷配音；矢量动画图解(A-roll) + gpt-image-2
情绪插画(B-roll) + 章节氛围背景板；单行字幕；结尾固定带互动提问或下集钩子。
**版权原则**：史实(时间/事件/人物)来自公开史料不受版权保护；全部句子原创，不引用任何小说原文。
**生产流程（每集）**：按本大纲写 8 章文案 JSON → `prepare.py` 配音 → `src/broll/generate.py`
生成插画/背景板 → `vector_render.py --render` → 门禁+ffprobe → NAS 试听 → 确认后转正/发布。

第 01 集已完成：《靖难之役》。第 02 集为回溯前传，之后按时间线推进。

### 第02集 · 朱元璋：从乞丐到皇帝（前传回溯）
- 时间：1328-1398
- 钩子：中国历史上出身最低的开国皇帝——要懂后面所有的故事，得先讲他
- 锚点：濠州赤贫、全家饿死、皇觉寺讨饭 → 1352 投红巾军 → 鄱阳湖灭陈友谅 → 1368 称帝北伐 → 废丞相、杀功臣（胡惟庸/蓝玉）→ 分封诸王 → 1398 驾崩
- 收尾：他把一切都安排好了，唯独没算到——尸骨未寒，亲儿子造了孙子的反（衔接第 01 集）
- 插画点：皇觉寺孤僧、鄱阳湖水战、奉天殿称帝

### 第03集 · 朱棣：抢来的皇位坐得稳吗
- 时间：1402-1424
- 钩子：造反成功只是开始，坐稳才是本事
- 锚点：永乐大典（1408）、郑和六下西洋（1405-1422）、迁都北京与紫禁城（1421）、五征漠北、设奴儿干都司
- 收尾：一个用不正当手段上台的皇帝，却干出了超越父亲的功业——但花销也掏空了国库
- 插画点：新落成的紫禁城、宝船队出海、漠北风雪行军

### 第04集 · 朱高炽与朱瞻基：胖皇帝和蛐蛐皇帝的十年
- 时间：1424-1435
- 钩子：一个当了十个月皇帝就累死了，一个被骂"促织天子"却缔造了盛世
- 锚点：仁宗赦建文旧臣、平反冤狱；宣宗三杨辅政、废后风波、蛐蛐天子典故、宣德炉；1449 前的最后繁荣
- 收尾：盛世之下，一个巨大的隐患正在北方草原悄悄长大——瓦剌也先
- 插画点：紫禁城朝堂、宣德炉与蛐蛐罐

## 第二部 · 北望与南渡（正统 → 天顺）

- 时间：1435-1449
- 钩子：二十万大军、一个宦官、五十个贵族战死——皇帝本人成了蒙古人的俘虏
- 锚点：王振专权、正统亲征、土木堡惨败（1449）、张辅/英国公等勋贵尽没、也先挟帝叩关
- 收尾：皇帝被抓、京城空虚、朝堂哭成一片——有人喊南迁，有个人站了出来
- 插画点：土木堡残阳、溃军与风沙

### 第06集 ✅ · 北京保卫战：于谦的孤注一掷
- 时间：1449-1457
- 钩子："言南迁者可斩"——一个文官撑住了整个帝国
- 锚点：于谦整军、立郕王（景泰）、也先攻北京受挫（1449.10）、夺门之变（1457）、于谦被杀"粉身碎骨浑不怕"
- 收尾：救了帝国的人被帝国杀了；八年后平反时，天下为他们父子流泪
- 插画点：德胜门守军、于谦官服立像、夺门夜宫变

## 第三部 · 中兴与荒唐（成化 → 正德）

### 第07集 · 成化朝：大十七岁的万贵妃与西厂特务
- 时间：1464-1487
- 钩子：皇帝恋着大自己十七岁的宫女，特务机构又添一家
- 锚点：万贵妃专宠、汪直与西厂、成化犁庭（荡平建州女真）、纸糊三阁老

- 插画点：宫墙深院、西厂缇骑

### 第08集 · 弘治中兴：只娶一个人的皇帝
- 时间：1487-1505
- 钩子：一夫一妻、每天早朝、拼命干活——明朝最标准的"好皇帝"
- 锚点：驱逐奸佞、尽革弊政、弘治君臣（刘大夏/马文升）、财务与治河整顿
- 收尾：他把帝国修修补补交给了史上最会玩的儿子
- 插画点：早朝百官、弘治帝批阅奏章

### 第09集 · 正德朝：不想当皇帝的皇帝
- 时间：1505-1521
- 钩子：建豹房、自封大将军、给自己发工资——皇帝当成了副业
- 锚点：刘瑾专权与被剐、应州大捷（1517，亲自砍人）、宁王之乱（1519）与王阳明四十三天平叛、正德落水
- 收尾：玩了一辈子，落水后一病不起，没留儿子——皇位落到了堂弟头上
- 插画点：豹房游乐、应州战场烽烟、王阳明书生领兵

## 第五部 · 张居正与三大征（万历）

### 第13集 · 张居正：帝国最后的裱糊匠
- 时间：1572-1582
- 钩子：一条鞭法、考成法——他一个人给帝国续命六十年
- 锚点：联合冯保逐高拱、万历幼年与李太后、考成法/一条鞭法、清丈田亩、戚继光镇蓟州
- 收尾：死后被抄家清算，长子自尽；他一死，帝国再无刹车的人
- 插画点：票拟批红、田亩丈量场景

### 第14集 · 万历亲政与国本之争
- 时间：1582-1600
- 钩子：立谁当太子这件事，皇帝和大臣冷战了十五年

- 收尾：皇帝用罢工对抗文官，赢得了家事，输掉了国事
- 插画点：空荡荡的朝堂、奏章堆积如山

### 第15集 · 万历三大征（上）· 宁夏与朝鲜之役
- 时间：1592-1598
- 钩子：丰臣秀吉要借道明朝打大明——万历的军队跨过鸭绿江
- 锚点：哱拜叛乱（宁夏）、朝鲜之役两次援朝（平壤大捷、碧蹄馆、露梁海战）、李如松/邓子龙
- 收尾：仗打赢了，辽东精锐也打空了——东北亚一个新的势力正在崛起
- 插画点：平壤城头明军旗帜、露梁海战火海

### 第16集 · 万历三大征（下）· 播州与帝国的裂缝
- 时间：1599-1600
- 钩子：三大征全胜，国库却见了底——帝国的钱都去哪了
- 锚点：播州之役平杨应龙、矿监税使四出、萨尔浒前夜的辽东（李成梁时代）、努尔哈赤崛起与十三副遗甲
- 收尾：帝国的军队还能打赢任何一场仗，但已经打不起任何一场仗了
- 插画点：播州山城、辽东雪原骑影

- 插画点：扬州城头史可法、赤嵌城受降、海峡帆影

## 每集生产清单（Checklist）

1. 按本大纲写 `src/mzx_story/ming-NN-<slug>.json`（voice/broll_style/bg/broll/8 章narration）
2. `prepare.py` 改 CONTENT 路径或参数化后配音（WSL CosyVoice）
3. `src/broll/generate.py --content ...`（插画 + 背景板，缺图渲染会报错）
4. `vector_render.py --render --out D:/ming-NN`（布局门禁 + ffprobe 自动校验）
5. NAS `临时-试听/明朝故事/` 试听 → 确认后转正
