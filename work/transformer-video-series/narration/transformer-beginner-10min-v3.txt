先看两句话。第一句是：“奖杯放不进箱子，因为它太大。”这里的“它”，通常指奖杯。第二句是：“奖杯放不进箱子，因为它太小。”这一次，“它”通常指箱子。只改了最后一个词，指代就变了。人会自动利用上下文完成判断，计算机却只收到一串符号。上下文，就是某个位置周围、能够帮助理解它的信息。Transformer 的任务，就是把符号变成数字，再让每个位置从上下文中取得有用的信息。接下来我们沿着这两句话走一遍。你会看到文字怎样进入模型，注意力怎样计算，GPT 又怎样训练和生成。

模型收到文字后，先做 Tokenization，也就是把文字切成便于处理的小块，叫作 Token。Token 不一定等于一个汉字，也不一定等于一个完整单词；它可能是字、词片段、数字或标点。每个 Token 会被换成一个整数编号。编号只是查表用的索引，就像图书馆的书号，本身不代表书的内容。模型拿编号查询嵌入表，取出一串可训练的数字，这就是 Embedding，中文叫嵌入。向量，就是一列有固定顺序的数字；这里不用把它想成几何箭头，只要把它理解成模型描述一个 Token 的数字档案。向量里的每个数字叫一个维度，维度越多，档案里能容纳的特征位置就越多。嵌入表可以理解成一张会在训练中不断修改的“编号到数字档案”对照表。初始档案还不知道当前句子的含义，所以“它”在两句话里查出的向量相同。模型还会加入位置信息，让“奖杯放进箱子”和“箱子放进奖杯”不再被当成同一组词。到这里，文字已经变成带位置的向量序列，可以交给神经网络计算。

在 Transformer 出现以前，RNN 常按顺序处理句子。第一个位置把记忆交给第二个，第二个再交给第三个。距离一长，信息要经过很多站；训练也难以把所有位置同时算完。Self-Attention，中文叫自注意力，改变了这条信息路线。所谓“自”，表示比较的对象来自同一段输入；所谓“注意力”，表示模型会为不同位置分配不同的重要程度。一个位置可以直接和其他位置比较，不必沿着链条逐站传递。这里要补一个重要限定。编码器里的双向注意力，可以查看左右两边的完整输入。GPT 使用因果遮罩；遮罩可以理解成一张访问权限表，它把未来位置盖住，每个位置只能查看自己和左侧已经出现的 Token，不能偷看未来答案。所以“每个词看全句”只是入门直觉。更准确的说法是：每个位置都能直接查看规则允许它查看的上下文。

注意力怎样知道该看谁？每个输入向量会同时经过三次不同的线性变换，得到 Query、Key 和 Value。线性变换，可以先理解成一台可调参数的数字混合器：它把输入向量重新组合，从同一份档案提取不同用途的信息。它们不是先后流过的三道工序，而是同一份输入产生的三种表示。Query 表示当前位置正在寻找什么。Key 表示每个位置提供什么匹配线索。Value 表示匹配成功后真正取回什么信息。处理“它”时，模型拿“它”的 Query，分别和“奖杯”“箱子”“太大”等位置的 Key 做点积。点积的算法，是把两列数字对应相乘，再把乘积相加；两列数字越同向，结果通常越大，所以这里把它当作匹配分数。比如二乘一，加一乘三，点积就是五。实际计算还会除以 Key 维度的平方根。维度多时，点积容易整体变大，这一步像把音量调回合适范围，避免后面的权重过早变得极端。接下来，匹配分数会交给 Softmax，而 Value 暂时在旁边等待。

我们用三个玩具分数走一次完整计算。假设“它”的 Query 和三个 Key 比较后，得到二点零、一点零和零点五。Softmax 是一个“分数转权重”的函数：它先把任意大小的分数变成正数，再除以总和，得到一组总和为百分之百的比例。分数之间的高低关系会保留，但现在可以直接解释成该参考多少。最后大约得到百分之六十三、百分之二十三和百分之十四。模型再用这三个比例，分别乘上三个位置的 Value，并把结果相加。这叫加权求和，也就是重要的多取一些，不重要的少取一些。得到的新向量，就是“它”融合上下文后的表示。换成“因为它太小”，前面各层形成的向量会改变，匹配分数也可能改变，于是“箱子”获得更高权重。这里的数字只是演示。真实权重由数据学习，而且会随层、注意力头和上下文变化。

一个注意力头，就是一套独立的 Query、Key、Value 变换和匹配计算。Transformer 会并行计算多个头，等于让多个观察角度同时阅读一句话。有的头可能对近距离搭配敏感，有的可能对指代或句法结构敏感，但这些职责不是工程师提前写死的，也不保证每个头都能被人清楚命名。各个头的结果会拼接起来，再经过一次输出投影。随后是残差连接。残差不是“剩余误差”，在这里它指一条捷径：把这一层处理前的输入直接加回输出，避免原信息在很多层加工后丢失。归一化再把数值调整到较稳定的尺度，让深层网络更容易训练。接着是前馈网络，简称 FFN。它像每个位置各自使用的同一套小型加工站，对向量做非线性变换；非线性意味着结果不只是简单按比例放大，因此能组合出更复杂的特征。注意力负责位置之间交流，前馈网络负责位置内部加工。把这套结构重复很多层，简单线索就能逐步组合成更抽象的上下文表示。

Transformer 并不只有一种外形。编码器可以理解成阅读器，负责把已有输入读成上下文表示；解码器可以理解成写作者，负责按顺序产生新内容。原始论文采用编码器加解码器，适合机器翻译：编码器先双向读取源句，解码器一边查看编码结果，一边生成目标句。BERT 一类模型主要使用编码器，擅长理解、分类和抽取。GPT 一类模型主要使用解码器，并用因果遮罩预测下一个 Token。三种结构共享注意力、前馈网络、残差连接和归一化，但信息可见范围不同。画注意力连线时，必须同时说明遮罩规则。否则“所有位置互相连接”的图可能适合编码器，却会错误描述 GPT。理解这个区别，也就理解了为什么 GPT 训练时不能利用未来词作弊。

GPT 的预训练目标很朴素：根据左侧内容，预测真实出现的下一个 Token。以“今天天气很热”为例，输入和目标错开一位。“今天”之后预测“天气”，“天气”之后预测“很”，“很”之后预测“热”。训练数据里的实际 Token 就是监督信号，并不是语言中唯一合理的答案。模型内部可被训练修改的数字叫参数；训练的目的，就是把大量参数一点点调到更合适的位置。如果模型在“很”后面给“冷”较高概率，而数据目标是“热”，交叉熵损失就会增大。交叉熵可以把它理解成一张罚分表：正确答案的概率越低，罚分越高；概率越高，罚分越低。反向传播会从这笔罚分倒着追查，计算每个参数对错误贡献了多少、应该往哪个方向调整。优化器再根据这些调整方向真正更新参数。虽然生成必须逐个 Token 进行，训练却能借助因果遮罩，同时计算一段文本中许多位置的预测。海量样本反复执行后，模型把语言规律和大量关联压缩进参数。

真正生成时，提示词先经过多层 Transformer，最后得到词表中每个候选 Token 的原始分数，也叫 Logits。Logits 还不是概率，可以有正有负；Softmax 才把它们变成总和为百分之百的概率分布。系统可以总选最高概率，也可以进行采样，也就是按照概率带一点随机性地抽取。温度控制概率是更集中还是更平坦；Top-k 只保留分数最高的 k 个候选；Top-p 则保留累计概率达到某个门槛的一小组候选。它们都在控制“稳妥”和“多样”之间的取舍。选出的 Token 被追加到上下文，再预测下一枚 Token。为了避免每一步都重算全部历史，推理系统会保存旧 Token 的 Key 和 Value，这就是 KV Cache。Cache 就是缓存，KV Cache 相当于把之前算好的匹配线索和待取信息放进临时工作台；新一步只计算新增 Token 的 K 和 V，再读取旧结果。显存是显卡上供模型高速使用的内存。缓存能明显加速生成，但上下文越长，工作台上保存的 K 和 V 越多，占用的显存也越多。

现在把整条路线连起来。文字先切成 Token，Token 编号查询嵌入，变成数字档案，再加入位置信息。每一层同时生成 Q、K、V，用 Query 和 Key 的点积算匹配分数，用 Softmax 得到总和为一的权重，再对 Value 加权求和。多头结果合并后，经过残差、归一化和前馈网络。训练时，模型用交叉熵衡量预测与数据答案的差距，再通过反向传播更新参数。生成时，它根据已有上下文反复选择下一枚 Token，并用 KV Cache 复用历史计算。Transformer 很强，但注意力权重不等于人类式的理解，也不能保证事实正确。它仍可能编造、继承偏见或受提示方式影响。抓住“表示、匹配、汇总、预测”这四步，你就抓住了 Transformer 的核心骨架。
